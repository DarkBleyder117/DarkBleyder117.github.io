CONTROL LED

Sin conexión
Bluetooth no disponible en este dispositivo. Usa un teléfono Android con Bluetooth activado. Mientras tanto puedes usar la vista previa.

Temas

Color · Perímetro

Efectos

Cada exhibidor junta solo su Q y su Perímetro por el número (ej. Q XB1 + Perímetro XB1).

Drivers

Nombra cada driver como Q XB1 o Perímetro XB1. Los que tienen el mismo número se enlazan solos como un exhibidor.

Respaldo

Ayuda

Antes de conectar, cierra cualquier otra aplicación de control de iluminación: cada driver acepta un solo teléfono a la vez.

Para dar de alta un driver, enciende solo ese exhibidor, toca Agregar driver y elige el que aparezca. El driver parpadea 3 veces para confirmarlo.

Si al probar no ves rojo, verde y azul en ese orden, ajusta el orden de color del driver.
